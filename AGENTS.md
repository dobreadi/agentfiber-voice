# Agent guidance

For work on these voice packages, read the shared [AgentFiber voice skill](packages/agentfiber-voice/skills/agentfiber-voice/SKILL.md). The [skills index](SKILLS.md) describes its coverage and installation.

Keep package boundaries explicit: ASR returns data, grammar returns proposals, visuals observe state, and the consuming application owns authority and execution. Use [CONTRIBUTING.md](CONTRIBUTING.md) for validation and release procedures.
